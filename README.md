# YOLO Training Dataset Manager

Проект для захвата и аннотации изображений с камеры из ros топика с помощью ROI (Region of Interest) для обучения модели YOLO детекции объектов.

## 📋 Описание

Это ROS 2 приложение позволяет:
- **Захватывать изображения** с топика ros2
- **Выделять ROI** (области интереса) с помощью мыши
- **Аннотировать объекты** с указанием класса
- **Автоматически генерировать** label-файлы в формате YOLO
- **Управлять датасетами** — создавать новые или дополнять существующие
- **Сохранять классы** в YAML конфигурации для обучения

## 🚀 Требования

- **Python 3.10+**
- **ROS 2** (Humble или новее)
- **OpenCV** (`opencv-python`)
- **PyTorch** (`torch`, `torchvision`)
- **Ultralytics** (`ultralytics`)
- **PyYAML** (`pyyaml`)

## 🎮 Использование

### 1️⃣ Захват и аннотация изображений

```bash
python capture_images.py
```

**Управление:**
- **SPACE** — начать выделение ROI (нарисовать прямоугольник)
- **ESC** — отменить выделение ROI
- **ENTER** — сохранить фото с аннотацией
- **C** — изменить класс объекта (вводится через консоль)
- **Q** — выход из программы

**Процесс:**
1. При запуске программа спрашивает:
   - Дополнить ли существующий датасет
   - Или создать новый (`dataset_1`, `dataset_2`, и т.д.)

2. Выделите прямоугольник вокруг объекта левой кнопкой мыши
3. Нажмите ENTER для сохранения
4. Фото автоматически сохранится в `dataset_N/images/`
5. Label-файл создастся в `dataset_N/labels/`

**Формат label-файла (YOLO):**
```
<class_id> <x_center> <y_center> <width> <height>
```
Все координаты нормализованы относительно размера изображения (0-1).

### 2️⃣ Обучение модели

После аннотации изображений запустите обучение:

```bash
python import_and_train.py
```

**Параметры обучения в `import_and_train.py`:**
```python
model.train(
    data='dataset_1/dataset.yaml',  # Путь к датасету
    epochs=100,                      # Количество эпох
    imgsz=640,                       # Размер входного изображения
    device='cuda',                   # GPU или CPU
    batch=16,                        # Размер батча
    patience=20,                     # Early stopping
    save=True,                       # Сохранять чекпойнты
    plots=True,                      # Генерировать графики
)
```

**Результаты сохранятся в:**
```
runs/detect/train/
├── weights/
│   ├── best.pt     # Лучшая модель
│   └── last.pt     # Последняя модель
├── results.csv     # Метрики обучения
└── plots/          # Графики
```

### 3️⃣ Экспорт модели

После обучения модель экспортируется в ONNX формат:

```bash
# Модель будет сохранена как yolo11n.onnx
```

## 📊 Примеры

### Добавление нескольких объектов на одном изображении

Если на одном фото несколько объектов:
1. Захватите фото
2. Выделите первый ROI и нажмите ENTER
3. Программа автоматически повторно использует то же изображение
4. Выделите второй ROI и нажмите ENTER
5. И так далее...

Label-файл будет содержать несколько строк (по одной на каждый объект):
```
0 0.45 0.35 0.3 0.4
0 0.75 0.65 0.25 0.35
```

### Работа с существующим датасетом

При повторном запуске `capture_images.py`:
```
Найдены существующие датасеты:
  1. dataset_1 (фото: 50)
  2. dataset_2 (фото: 30)

Выберите датасет (номер) или нажмите Enter для создания нового: 1
```

Программа загрузит классы из `dataset_1/dataset.yaml` и продолжит добавлять фото.

## 🔧 Конфигурация датасета

`dataset.yaml` автоматически генерируется с указанием:
```yaml
path: /path/to/dataset_1
train: images
val: images
test: images
nc: 2                    # Количество классов
names:
  0: object
  1: person
```

## ⚠️ Известные проблемы и решения

### Проблема: "Unable to import Axes3D" warning
**Решение:** Можете проигнорировать — это просто warning от matplotlib

### Проблема: "FileNotFoundError: yolov11n.pt"
**Решение:** Модель загружается автоматически при первом запуске `import_and_train.py`. Проверьте интернет соединение. Попробуйте другую модель yolo, например yolo8n.pt, 11-я версия подгрузится вместе с ней

### Проблема: Камера не работает
**Решение:** Проверьте топик ROS:
```bash
ros2 topic list | grep camera
ros2 topic echo /camera/image_color
```

### Проблема: CUDA недоступна
**Решение:** Измените `device='gpu'` на `device='cpu'` в `import_and_train.py`

## 🎯 Рабочий процесс

1. **Подготовка:** Подключите камеру к компьютеру
2. **Захват:** Запустите `capture_images.py` и аннотируйте ~50-100 изображений
3. **Обучение:** Запустите `import_and_train.py` для обучения модели
4. **Оценка:** Проверьте результаты в `runs/detect/train/`
5. **Итерация:** При необходимости добавьте больше изображений и переобучите
